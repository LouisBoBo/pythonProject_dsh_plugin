## 1. 装失败自动回退旧版

脚本：[`scripts/internal-market/install-latest.sh`](../../scripts/internal-market/install-latest.sh)

- 安装前：若已有旧目录，先 `mv` 到临时备份
- 解压 / 布局校验 / 版本核对失败：把备份 `mv` 回原处
- 成功：删除备份

> 仅覆盖走本脚本的安装路径。市场 UI 若走宿主自带安装器，仍按人工回滚。

## 2. 四套软件兼容声明

四套：

| 组件 | 含义 |
| --- | --- |
| workbuddy | WorkBuddy / DSH 宿主 |
| dsh_runtime | cordis + dsh-tools |
| plugin_cursor_coding | `@zhongruan/dsh-cursor-coding` |
| cursor_sdk | `@cursor/sdk` |

- 矩阵：`dsh-cursor-coding/compat-matrix.json`（生态副本：`company-registry/compat-matrix.json`）
- 插件 `package.json` → `zhongruanCompat`
- 运行时：`GET /health` → `compat`（**仅上报，不阻断写码**）
- 宿主版本：读 `WORKBUDDY_VERSION` / `DSH_APP_VERSION`；未知则 soft 通过

---

## 3. 写码服务子进程隔离

- 默认 `CURSOR_CODING_SERVER_MODE=auto`：优先拉起独立 Node 跑 HTTP；失败则回退同进程
- `inplace`：强制旧行为（同进程）
- `child`：强制子进程（启动失败则报错，不回退）
- HITL / pending 确认单已落盘到 `~/.zhongruan/cursor-coding/state/`，跨进程共享

**边界**：子进程挂了，聊天壳与工具注册仍在；`client.js` 仍在宿主页面上下文，页面级 JS 崩仍可能影响该页。
