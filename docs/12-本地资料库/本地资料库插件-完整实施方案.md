# 本地资料库插件 实现计划

> **面向实现者：** 按下面任务顺序做。步骤使用复选框（`- [ ]`）跟踪进度。每步写完再跑该步给出的命令，看到预期输出再进入下一步。
>
> **状态**：方案可实施（2026-10-21）  
> **落点**：本仓库独立 DSH Bundle `@zhongruan/dsh-mom-docs`（目录 `plugins/dsh-mom-docs/`）  
> **交付形态**：公司插件市场安装。开发机可以用本地 link 联调，发现页看不到本地 link。  
> **产品一句话**：对话里已经写好的文档，按调用参数落到「当前工作区 / MOM / 上海时区当天日期 / 文件」。

**目标：** 新增一个只负责本地落盘的资料库插件，把聊天里明确交出的文档写成工作区文件，并能按日期列出、读回。

**架构：** 插件在 `apply()` 里注册三个对话工具。模型调用时带上工作区绝对路径、文件名和正文。插件校验路径与文件名，写入 `{工作区}/MOM/{YYYY-MM-DD}/文件`，同名不覆盖。聊天记忆仍在 DSH 的工具结果里；日期目录里的 `_index.jsonl` 只做标题辅助，列表以目录里的真实文件为准。

**技术栈：** TypeScript、Node.js 22、`@deepseek-ai/cordis`、`@deepseek-ai/dsh-tools`。无 HTTP 服务、无侧栏、无第二套配置页。

## 0. 这是什么

| 是 | 边界 |
|----|------|
| 独立 DSH 插件，对话工具把一份文档写成工作区里的文件 | 不改 WorkBuddy 引擎、不改其它插件源码 |
| 路径固定为 `{directory}/MOM/{上海日历日}/{文件名}` | `MOM` 是字面目录名，P0 不做成可配置 |
| 只认工具参数 `directory` / `filename` / `title` / `content` / `date` | 不扫描用户原话或助手正文来决定是否保存 |
| 明文 `.md` / `.txt`，人可以用资源管理器直接打开 | 不写入知识库 sqlite，不参与召回 |
| 成功或失败都在工具结果里带 `code` | 已写入的文件不会因为索引追加失败而删除 |

和现有插件的关系：

| 现有能力 | 本插件 |
|----------|--------|
| `@zhongruan/dsh-knowledge` 导入文档并召回 | 互不调用。资料库文件不会自动进知识库 |
| `@zhongruan/dsh-cursor-coding` / `dsh-cursor-chat` 改工程源码 | 互不调用。写码结果不进 `MOM` |
| `@zhongruan/dsh-pcb-8d` 草稿在 `~/.zhongruan/pcb-8d-drafts` | 互不调用。8D 导出不会自动抄进 `MOM` |
| 用量计量 `@zhongruan/dsh-llm-meter` | 不改计量公式，不拦截 `llm/stream` |

## 1. 硬约束

| # | 约束 | 做法 |
| --- | --- | --- |
| 1 | 不动 WorkBuddy | 不改引擎，不读不写插件里的 MES / LLM / 企微配置。本插件没有业务凭证 |
| 2 | 不影响其它插件 | 新目录 `plugins/dsh-mom-docs/`；工具前缀 `zr_mom_`；patch id `mom-docs`。打包只增加本包 |
| 3 | 聊天认 DSH | 不另造会话。下一轮要记得路径，靠工具结果里的 `filePath` |
| 4 | 契约字段权威 | 保存、列表、读取只认参数和 `MomError.code`。禁止用正文匹配「保存」「纪要」「取消」 |
| 5 | 路径必须落在声明的工作区内 | `directory` 是已存在的绝对路径目录。最终文件的相对路径不得以 `..` 开头 |
| 6 | 同名不覆盖 | 已有 `周会纪要.md` 时写成 `周会纪要-2.md`。P0 没有覆盖参数 |
| 7 | 日期用上海时区日历日 | `Asia/Shanghai` 的 `YYYY-MM-DD`。禁止用 `toISOString().slice(0, 10)` |
| 8 | 最小写入面 | 只创建 `MOM/<日期>/` 下的 `.md`、`.txt` 和 `_index.jsonl`。不改工作区其它文件 |

对应目录的锁定解释：`directory` 就是当前对话所绑定的工程根目录，由模型按当前工作区填写绝对路径。插件不设默认家目录。目录不存在、不是绝对路径、是符号链接、或落在系统目录时，返回 `code=directory_invalid`。

## 2. 用户路径

```text

  → 完全退出江西中软工作助手再打开

  用户在已打开的工程里说：「把刚才的周会纪要存到资料库」

  → 工具卡回显相对路径 MOM/2026-10-21/周会纪要.md

  再次保存「周会纪要」
  → 新文件 MOM/2026-10-21/周会纪要-2.md
  → 原文件字节不变

路径 C · 查看与读回
```

## 3. 错误码

工具成功和失败都返回对象，不把业务失败抛成无码异常。`code` 只有下表这些值。

| code | 何时 |
|------|------|
| `ok` | 成功 |
| `directory_invalid` | 目录空、含 `\0`、非绝对路径、不存在、不是目录、是符号链接、位于系统目录、日期非法、最终路径越界 |
| `filename_invalid` | 文件名为空、是 `.` / `..`、以 `.` 开头、扩展名不是 `.md` / `.txt`、敏感文件名、读取时文件不存在 |
| `content_empty` | 正文 trim 后为空 |
| `content_too_large` | UTF-8 超过 512 KiB（512 × 1024 字节） |
| `write_failed` | 创建目录或写入文件失败；同名序号超过 100 |

未知异常对外也返回 `write_failed`，消息固定为「保存失败」，不把系统异常原文回给对话。

```typescript
import { existsSync, lstatSync, realpathSync } from 'node:fs'
import { homedir } from 'node:os'
import { basename, extname, isAbsolute, join, relative, resolve, sep } from 'node:path'
import { MomError } from './types.js'

const ALLOWED_EXT = new Set(['.md', '.txt'])

const SENSITIVE_BASENAMES = new Set([
  '.env',
  'credentials.json',
  'id_rsa',
  'id_ed25519',
])

const SENSITIVE_SUFFIXES = ['.pem', '.key', '.p12', '.pfx', '.env']

function blockedRoots(): string[] {
  const roots = [
    '/etc',
    '/sys',
    '/proc',
    '/dev',
    '/bin',
    '/sbin',
    '/usr/bin',
    '/usr/sbin',
    '/root',
    '/System',
    '/private/etc',
  ]
  if (process.platform === 'win32') {
    const sys = process.env.SystemRoot || 'C:\\Windows'
    roots.push(sys, join(sys, 'System32'))
    const pf = process.env.ProgramFiles
    const pf86 = process.env['ProgramFiles(x86)']
    if (pf) roots.push(pf)
    if (pf86) roots.push(pf86)
  }
  return roots.map((item) => resolve(item))
}

function isBlocked(dir: string): boolean {
  const abs = resolve(dir)
  return blockedRoots().some((root) => abs === root || abs.startsWith(root + sep))
}

export function shanghaiDate(now = new Date()): string {
  const formatted = new Intl.DateTimeFormat('en-CA', {
    timeZone: 'Asia/Shanghai',
    year: 'numeric',
    month: '2-digit',
    day: '2-digit',
  }).format(now)
  return assertCalendarDate(formatted)
}

export function assertCalendarDate(raw: string): string {
  const date = String(raw || '').trim()
  if (!/^\d{4}-\d{2}-\d{2}$/.test(date)) {
    throw new MomError('directory_invalid', '日期格式必须是 YYYY-MM-DD')
  }
  const [year, month, day] = date.split('-').map((part) => Number(part))
  const utc = new Date(Date.UTC(year, month - 1, day))
  if (
    utc.getUTCFullYear() !== year ||
    utc.getUTCMonth() !== month - 1 ||
    utc.getUTCDate() !== day
  ) {
    throw new MomError('directory_invalid', '日期不存在')
  }
  return date
}

export function resolveWorkspaceDir(raw: string): string {
  const text = String(raw || '').trim()
  if (!text || text.includes('\0')) {
    throw new MomError('directory_invalid', '目录为空')
  }
  const expanded = text.replace(/^~(?=\/|\\|$)/, homedir())
  if (!isAbsolute(expanded)) {
    throw new MomError('directory_invalid', '目录必须是绝对路径')
  }
  let abs: string
  try {
    abs = resolve(expanded)
  } catch {
    throw new MomError('directory_invalid', '目录无法解析')
  }
  if (isBlocked(abs)) {
    throw new MomError('directory_invalid', '目录位于系统路径')
  }
  if (!existsSync(abs)) {
    throw new MomError('directory_invalid', '目录不存在')
  }
  let stat: ReturnType<typeof lstatSync>
  try {
    stat = lstatSync(abs)
  } catch {
    throw new MomError('directory_invalid', '目录不可读')
  }
  if (stat.isSymbolicLink()) {
    throw new MomError('directory_invalid', '拒绝符号链接目录')
  }
  if (!stat.isDirectory()) {
    throw new MomError('directory_invalid', '路径不是目录')
  }
  return realpathSync(abs)
}

export function momDayDir(workspace: string, date: string): string {
  const day = assertCalendarDate(date)
  const dir = join(workspace, 'MOM', day)
  assertInside(workspace, dir)
  return dir
}

export function assertInside(root: string, target: string): string {
  const rel = relative(root, target)
  if (!rel || rel.startsWith('..') || isAbsolute(rel)) {
    throw new MomError('directory_invalid', '路径超出工作区')
  }
  return target
}

export function safeFileName(rawName: string, rawTitle: string): string {
  const source = String(rawName || '').trim() || String(rawTitle || '').trim()
  if (!source) throw new MomError('filename_invalid', '缺少文件名')
  let base = basename(source.replace(/\\/g, '/'))
  base = base.replace(/[\u0000-\u001f]/g, '')
  base = base.replace(/[<>:"|?*]/g, '-')
  base = base.replace(/\s+/g, ' ').trim().replace(/[. ]+$/g, '')
  if (!base || base === '.' || base === '..' || base.startsWith('.')) {
    throw new MomError('filename_invalid', '文件名不合法')
  }
  let ext = extname(base).toLowerCase()
  let stem = ext ? base.slice(0, -ext.length) : base
  if (!ALLOWED_EXT.has(ext)) {
    if (ext) throw new MomError('filename_invalid', '只允许 .md 或 .txt')
    ext = '.md'
  }
  stem = stem.replace(/[. ]+$/g, '').trim()
  if (!stem) throw new MomError('filename_invalid', '文件名不合法')
  if (stem.length > 80) stem = stem.slice(0, 80).replace(/[. ]+$/g, '')
  const fileName = `${stem}${ext}`
  const lower = fileName.toLowerCase()
  if (
    SENSITIVE_BASENAMES.has(lower) ||
    SENSITIVE_SUFFIXES.some((suffix) => lower.endsWith(suffix))
  ) {
    throw new MomError('filename_invalid', '拒绝敏感文件名')
  }
  return fileName
}

export function toPortableRelative(root: string, target: string): string {
  return relative(root, target).split(sep).join('/')
}
```

`safeFileName` 的规则：

- 只取最后一段，`a/../../周会.md` 变成 `周会.md`
- 无扩展名时补 `.md`
- `.MD` / `.TXT` 规范成小写扩展名
- 主文件名最长 80 个字符
- `.exe`、`.env`、`.pem`、`.key` 拒绝

```typescript
import {
  appendFileSync,
  existsSync,
  mkdirSync,
  readdirSync,
  readFileSync,
  renameSync,
  statSync,
  writeFileSync,
} from 'node:fs'
import { extname, join } from 'node:path'
import {
  assertInside,
  momDayDir,
  resolveWorkspaceDir,
  safeFileName,
  shanghaiDate,
  toPortableRelative,
} from './paths.js'
import { MomError, type ListedDoc, type SaveResult } from './types.js'

export const MAX_BYTES = 512 * 1024

function withTrailingNewline(content: string): string {
  return content.endsWith('\n') ? content : `${content}\n`
}

function uniqueFileName(dir: string, fileName: string): string {
  const ext = extname(fileName)
  const stem = fileName.slice(0, -ext.length)
  for (let n = 1; n <= 100; n += 1) {
    const candidate = n === 1 ? fileName : `${stem}-${n}${ext}`
    if (!existsSync(join(dir, candidate))) return candidate
  }
  throw new MomError('write_failed', '同名文件超过 100 个')
}

export function saveDocument(input: {
  directory: string
  filename: string
  title: string
  content: string
  now?: Date
}): SaveResult {
  const workspace = resolveWorkspaceDir(input.directory)
  const now = input.now ?? new Date()
  const date = shanghaiDate(now)
  const requested = safeFileName(input.filename, input.title)
  const text = String(input.content ?? '')
  if (!text.trim()) throw new MomError('content_empty', '正文为空')
  const body = withTrailingNewline(text)
  const bytes = Buffer.byteLength(body, 'utf8')
  if (bytes > MAX_BYTES) throw new MomError('content_too_large', '正文超过 512 KiB')

  const dayDir = momDayDir(workspace, date)
  mkdirSync(dayDir, { recursive: true })
  const fileName = uniqueFileName(dayDir, requested)
  const filePath = assertInside(workspace, join(dayDir, fileName))
  const tmp = `${filePath}.${process.pid}.tmp`
  try {
    writeFileSync(tmp, body, { encoding: 'utf8' })
    renameSync(tmp, filePath)
  } catch (err) {
    throw new MomError('write_failed', err instanceof Error ? err.message : '写入失败')
  }

  const title = String(input.title || '').trim().slice(0, 120)
  let indexWritten = true
  try {
    appendFileSync(
      join(dayDir, '_index.jsonl'),
      JSON.stringify({ savedAt: now.toISOString(), date, fileName, title, bytes }) + '\n',
      'utf8',
    )
  } catch {
    indexWritten = false
  }

  return {
    filePath,
    relativePath: toPortableRelative(workspace, filePath),
    fileName,
    date,
    bytes,
    title,
    indexWritten,
  }
}

function readTitleIndex(dayDir: string): Map<string, { title: string; savedAt: string }> {
  const out = new Map<string, { title: string; savedAt: string }>()
  const indexPath = join(dayDir, '_index.jsonl')
  if (!existsSync(indexPath)) return out
  const lines = readFileSync(indexPath, 'utf8').split(/\r?\n/)
  for (const line of lines) {
    if (!line.trim()) continue
    try {
      const row = JSON.parse(line) as { fileName?: unknown; title?: unknown; savedAt?: unknown }
      if (typeof row.fileName !== 'string' || !row.fileName) continue
      out.set(row.fileName, {
        title: typeof row.title === 'string' ? row.title : '',
        savedAt: typeof row.savedAt === 'string' ? row.savedAt : '',
      })
    } catch {
      continue
    }
  }
  return out
}

export function listDocuments(
  directory: string,
  dateRaw: string,
  now = new Date(),
): { date: string; items: ListedDoc[] } {
  const workspace = resolveWorkspaceDir(directory)
  const date = String(dateRaw || '').trim() ? String(dateRaw).trim() : shanghaiDate(now)
  const dayDir = momDayDir(workspace, date)
  if (!existsSync(dayDir)) return { date, items: [] }
  const titles = readTitleIndex(dayDir)
  const names = readdirSync(dayDir)
    .filter((name) => {
      if (name.startsWith('_') || name.startsWith('.')) return false
      const ext = extname(name).toLowerCase()
      return ext === '.md' || ext === '.txt'
    })
    .sort()
  const items = names.map((fileName) => {
    const meta = titles.get(fileName)
    return {
      fileName,
      bytes: statSync(join(dayDir, fileName)).size,
      title: meta?.title || '',
      savedAt: meta?.savedAt || '',
    }
  })
  return { date, items }
}

export function readDocument(
  directory: string,
  dateRaw: string,
  filename: string,
  now = new Date(),
): { filePath: string; content: string; date: string; fileName: string } {
  const workspace = resolveWorkspaceDir(directory)
  const date = String(dateRaw || '').trim() ? String(dateRaw).trim() : shanghaiDate(now)
  const fileName = safeFileName(filename, '')
  const dayDir = momDayDir(workspace, date)
  const filePath = assertInside(workspace, join(dayDir, fileName))
  if (!existsSync(filePath) || !statSync(filePath).isFile()) {
    throw new MomError('filename_invalid', '文件不存在')
  }
  if (statSync(filePath).size > MAX_BYTES) {
    throw new MomError('content_too_large', '文件超过 512 KiB')
  }
  return { filePath, content: readFileSync(filePath, 'utf8'), date, fileName }
}
```

```typescript
import type { Context } from '@deepseek-ai/cordis'

export const name = 'mom-docs'

function textBlocks(text: string) {
  return [{ type: 'text' as const, text }]

function fail(err: unknown): { code: Exclude<MomCode, 'ok'>; message: string } {
  if (err instanceof MomError) return { code: err.code, message: err.message }
  return { code: 'write_failed', message: '保存失败' }

export function apply(ctx: Context): void {
  ctx.tools.register(
    defineTool({
      name: 'zr_mom_save',
      description:
        '把当前对话里已经写好的一份文档保存到本地资料库。' +

        'directory 填当前工程根目录的绝对路径。' +
        'filename 用简短文件名，可以不带扩展名，默认 .md；只允许 .md 或 .txt。' +
        'content 是要落盘的全文。' +
        '文件写到 {directory}/MOM/{上海时区当天日期}/{filename}。同名不覆盖，自动加 -2、-3。' +
        '不要用本工具改工程源码，不要写入知识库。',
      parameters: {
        directory: { type: 'string', required: true, description: '当前工程根目录绝对路径' },
        filename: { type: 'string', required: true, description: '文件名；可空，则使用 title' },
        title: { type: 'string', required: true, description: '标题；可空' },
        content: { type: 'string', required: true, description: '文档全文' },
      },
      output: {
        schema: {
          type: 'object',
          additionalProperties: false,
          properties: {
            ok: { type: 'boolean' },
            code: { type: 'string' },
            message: { type: 'string' },
            filePath: { type: 'string' },
            relativePath: { type: 'string' },
            fileName: { type: 'string' },
            date: { type: 'string' },
            bytes: { type: 'number' },
          },

            directory: String(args.directory ?? ''),

            title: String(args.title ?? ''),
            content: String(args.content ?? ''),
          })

            ok: true,
            code: 'ok',
            message: '已保存',
            filePath: saved.filePath,
            relativePath: saved.relativePath,

            bytes: saved.bytes,

            ok: false,
            code: failed.code,
            message: failed.message,

            relativePath: '',
            fileName: '',
            date: '',
            bytes: 0,
          }

    }),

    defineTool({
      name: 'zr_mom_list',
      description:
        '列出某个工作区本地资料库中某一天的文件。' +

        'date 传 YYYY-MM-DD；不知道日期就传空字符串，表示上海时区今天。',
      parameters: {
        directory: { type: 'string', required: true, description: '工程根目录绝对路径' },
        date: { type: 'string', required: true, description: 'YYYY-MM-DD；空字符串表示今天' },

              ? value.count
                ? `${value.date} 共 ${value.count} 份：\n${value.items}`

        'filename 必须使用 zr_mom_list 返回的文件名。' +

        date: { type: 'string', required: true, description: 'YYYY-MM-DD；空字符串表示今天' },
        filename: { type: 'string', required: true, description: '列表中的文件名' },
      },
      output: {
        schema: {
          type: 'object',
          additionalProperties: false,
          properties: {
            ok: { type: 'boolean' },
            code: { type: 'string' },
            message: { type: 'string' },
            filePath: { type: 'string' },
            fileName: { type: 'string' },
            date: { type: 'string' },
            content: { type: 'string' },
          },
        },
        render: (_args, value) =>
          textBlocks(value.ok ? `${value.fileName}\n${value.content}` : `未能读取：${value.code} ${value.message}`),
      },
      async execute(args) {

          const doc = readDocument(
            String(args.directory ?? ''),
            String(args.date ?? ''),

            ok: true,
```
