# 仓库目录说明

本仓库是公司 WorkBuddy（DSH）插件仓。浏览器「设置 → 插件市场 → 发现」里能装到的包，都从这里打包上传。版本以各插件 `package.json` 为准；下文版本为 2026-09-30 快照。

```text
pythonProject_dsh_plugin/
├── plugins/            ← 各独立插件源码（dsh-* Bundle）
├── docs/               ← 方案、手册、复盘、周报
├── scripts/            ← 打包上架、本机审码 Hook、远端审码部署
├── company-registry/   ← 内网市场本地产物（清单、npm 索引、nginx 参考）
├── templates/          ← 新插件起步模板
├── dist/               ← 已打好的 npm tgz
└── .cursor/rules/      ← 本仓库写码约束
```

---

## 根目录

| 目录 | 作用 |
| --- | --- |
| `plugins/` | 各独立插件源码。每个 `dsh-*` 是一个可单独打包的 Bundle。 |
| `docs/` | 按主题归档的方案、手册、复盘和周报。实施以各文正文为准，索引入口见 [`README.md`](./README.md)。 |
| `scripts/` | 打包上架、本机审码 Hook、远端审码部署脚本。 |
| `company-registry/` | 公司内网插件市场的本地产物：目录清单、npm 元数据、nginx 参考配置。 |
| `templates/` | 新插件起步模板。复制到 `plugins/dsh-<短名>/` 再开发，模板目录本身不参与打包。 |
| `dist/` | 已打好的 npm 包。当前是 `dsh-cursor-chat` 的 `0.1.0` / `0.1.1` tgz。 |
| `.cursor/rules/` | 写码约束：配置只读 WorkBuddy「系统配置」、公司插件必须走市场安装、改完同步浏览器宿主、LLM 用量口径冻结。 |

## `scripts/` 与市场

| 路径 | 作用 |
| --- | --- |
| `scripts/internal-market/` | `pack.sh` 打包、`upload.sh` 上传、`install-latest.sh` 装到本机 WorkBuddy，另有生成目录、校验、本地 serve。 |
| `scripts/hook-review/` | 本机 `post-commit` 直接调引擎审码。 |
| `scripts/remote-review/` | 远端审码的公司机部署（systemd、smee、GitHub Actions）。 |
| `scripts/verify-cursor-chat.ps1` | `dsh-cursor-chat` 本机验证脚本。 |
| `company-registry/plugins.json` | 市场清单。上传脚本会核对线上目录，缺包会拒绝上传。 |
| `company-registry/npm/` | 已发布包的版本索引（`@zhongruan/dsh-*`）。 |
| `company-registry/artifacts/` | 打包产物暂存。 |
| `company-registry/nginx-*.conf` | 服务器 nginx 静态目录参考配置。 |

正式交付以市场安装为准。本机 `dsh plugin add ./` 只用于开发联调，不会出现在发现列表。
