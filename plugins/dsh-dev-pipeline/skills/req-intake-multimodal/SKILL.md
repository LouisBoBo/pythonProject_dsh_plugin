# 需求采集（第 1 步）

## 目标
把用户原话变成一条干净的、可被后续步骤消费的需求记录。

## 做法
1. 保留用户原话中的业务名词、页面/接口名、约束与验收口径。
2. 删除宿主注入的 runtime / memory / knowledge 段、工具回显、系统提示。
3. 纯文字、纯图片、图文混合三种来源都要能开工；图片只记路径与数量。
4. 只做清洗，不扩写，不套行业模板。

## 产出
`epic.raw_intake = { text, chars, images, one_liner, source }`

## 失败
- 文本与图片都为空：直接失败，不再往下跑。
- 需求含密钥/口令：先提醒用户移除，不要写入账本。
