# 工单全程追溯 SOP

用户问工单进度、这块板在哪、近几日工单时使用。只读 MES，不改工单。**不要升级成运营简报**。

## 取数（只许这两种 kind）

允许：`work_order`、`wip`。  
禁止：`output`、`yield`、`scrap`、`inventory`、`capacity`、`oee`。禁止为凑品质/产能/库存去补查。

1. 用户给了工单号或料号：`zr_esc_mes_query` `kind=work_order`，`keyword=工单号或料号`；再取 `kind=wip`，在在制列表里对同一工单/料号。日期按用户窗口传，没说窗口则可不传日期。
2. 没给工单号：按**用户说的时间窗口**取 `kind=work_order`，出工单状态表；可再取 `kind=wip` 对齐在制。不要改去产出/OEE/良率/库存。
3. 失败写出 `error.code`，禁止编造工序进度。

### 日期窗口（禁止写死 7 天）

`date_from` / `date_to` 用 `YYYY-MM-DD`，时区 Asia/Shanghai。

- 用户说近 N 天、近一周、近一个月、本周、本月、昨天、或给出起止日：**按原话换算**。近 N 天含今天，从今天往回 N−1 个自然日（近 10 天 ≠ 近 7 天）。
- 用户没说任何时间：才用近 7 日。
- 表头写清实际窗口（例如「2026-08-21～2026-09-19」），禁止口称 7 天却按别的天数取数。

## 判读

| 现象 | 工艺含义 |
|------|----------|
| 停在 SMT / 贴片 | 缺件、供料、锡膏或首件未过 |
| 停在 DIP / 插件 | 波峰、AOI 虚焊或连锡待修 |
| 停在组装 | 连接器、螺丝、功能半成品 |
| 停在测试 / 维修 | 功能不良回流，看工单状态字段，不要另查缺陷报表 |
| 工单已完工但无入库 | 报工与仓储不同步，先核单据不要判欠产 |

找不到工单：写「MES 无此单」，列出工具返回的相近单，不要猜。

## 输出（工单状态表，不是运营简报）

```
# 工单追溯
| 工单 | 料号 | 当前工序 | 产线区段 | 状态 | 计划/实际 | 证据 |
## 工艺落点
短段：这块板卡在哪、会堵哪条链。
## 建议
| 优先级 | 动作 | 谁来验证 |
```

有工序节点且图表已启用：最多一张 `funnel`（工序通过量）或 `column`（各站停留）。数字必须来自 `work_order` / `wip`。禁止为凑图补查其它 kind。
