# MES 生产运营分析 SOP（PCB 专家简报）

本技能在用户本轮原文命中触发短语、或场景卡「在本会话使用」后加载。只读，不改 MES。交付物必须让生产主管 **10 秒扫完风险、1 分钟看完证据**。

## 0. 禁止事项

- 禁止大段散文。能进表的数字、风险、建议一律表格；解释只用短段落（每段一个判断）。
- 禁止编造：所有现场数字来自 `zr_esc_mes_query`。工具失败写出 `error.code`，整节标「盲区」。
- 禁止只出 1 张图。图表连接器已启用且有可比点时，**必须调用 3～5 次** `zr_esc_mcp_chart`，类型尽量不重复。
- 禁止把计划量与实际量画在未声明口径的同一轴；单位不一致则 **不出 dual-axes**，改用表格写清口径冲突。
- 禁止用用户原话当 `kind`。不要升级 8D，除非用户明确要质量闭环（只提示已安装的 `pcb_8d_*`）。

## 1. 取数

按问题调用 `zr_esc_mes_query`，`kind` **只能**是：

| kind | 用途 |
|------|------|
| `capacity` | 设备利用率 / 稼动 |
| `output` | 日产出 |
| `oee` | 综合 OEE 及可用率/性能率/质量率 |
| `yield` | 综合良率、工序良率 |
| `scrap` | 报废与缺陷分布 |
| `inventory` | 物料库存与安全库存 |
| `wip` | 在制工单 |
| `work_order` | 指定工单号或料号 |

日期：`date_from` / `date_to` 用 `YYYY-MM-DD`；用户没说则查近 7 日（Asia/Shanghai）。库存、在制可不传日期。MES 未启用 → 停在「请到专家·技能·连接器打开 MES」，不要编数字。

全面运营分析默认取：`output`、`yield`、`scrap`、`inventory`，再尝试 `capacity`、`oee`、`wip`。404 记盲区，继续其它节。

## 2. PCB 工艺判读（必须落到工序，禁止空话）

把产线当成一条链：SMT 贴片 → DIP 插件/焊接 → 组装 → 测试。

| 现象 | 专家优先假设（有数才写） |
|------|--------------------------|
| 多条线跌幅接近 | 排产/报工入库/主料，而不是单台贴片机 |
| 达产率异常 | 先核计划单位 vs 实际单位（套/点）。不一致则达产率作废 |
| 巡检工序良率稳、综合不良率升 | 产出结构、低量日抽样或 KPI 字段为 0，不要误判某道工序崩了 |
| 虚焊 / 连锡 | 落点 DIP / AOI / 波峰 |
| 偏移、漏件 | 落点 SMT / 锡膏 / 供料 |
| 短路 | 落点组装连接器或功能测试漏出 |
| 主料库存=0 且安全库存>0 | SMT 停料风险（LED、连接器、基板优先） |
| `updated_at` 滞后 | **禁止**推算可生产天数 |
| utilization / oee 404 | 不能用产出跌幅代替停线结论，不能拆 OEE 三率 |

每条结论写清证据：kind / 日期 / 产线或工序 / 料号。

## 3. 出图（已启用 mcp-chart）

`labels`/`values`/`values2` 必须来自工具返回，等长，最多 12 点。每次调用后，正文用工具返回的 `![标题](url)` **紧贴对应表格**插入。

优先组合（有数据才画，缺则跳过，总数仍尽量 3～5 张）：

| 顺序 | 数据 | chart_type | 规则 |
|------|------|------------|------|
| 1 | 日产出（按日合计） | `area` 或 `line` | 标题写清单位（点/套） |
| 2 | 计划 vs 实际（单位一致时） | `dual-axes` | `values`=实际，`values2`=计划 |
| 3 | 产线产出对比 | `column` | SMT/DIP/组装/测试分开 |
| 4 | 缺陷件数 TOP | `funnel` 或 `pie` | funnel 按件数从大到小 |
| 5 | 工序良率 | `radar`（≥3 道工序）或 `bar` | 雷达标题写「工序一次合格率」 |
| 6 | 低于安全库存缺口 | `bar` | 缺口=安全库存−现存量，负缺口不画 |

未启用图表连接器：只用 Markdown 表，不要假装已出图。某次出图失败：保留表格，写 `error.code`，不要重试编数。
